# Security Policy

## Supported versions

Until versioned releases are published, security fixes target the latest
commit on `main`. After releases begin, this file will list the supported
release lines explicitly.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting flow for `systeampl/sshmgr` under **Security → Advisories
→ Report a vulnerability**. Include the affected command or configuration,
impact, reproduction steps, and any proposed remediation.

If that flow is unavailable, open a public issue containing no sensitive or
exploit details and ask the maintainers for a private reporting channel.

The maintainers will acknowledge a usable report, investigate it, and
coordinate disclosure and remediation with the reporter. No specific response
deadline is promised until a formal release/support process is established.
